# Post-processing — Merge PSI Across Cell Lines

Three-stage pipeline that converts per-replicate PSI text files (Step 2b output)
into the COMPASS master CSV. Stage 1 collapses ambiguous splice-junction events
to a single canonical Gencode-annotated junction; Stage 2 merges PSI across
replicates and cell lines; Stage 3 produces an SI table of PSI at every
non-chosen Gencode junction for the ambiguous events.

---

## Scripts

| Script | Role |
|--------|------|
| `01_fix_sj_supertable.py` | Stage 1 — pick a canonical junction per ambiguous event; rewrite supertable + per-rep PSI text files at the chosen junction. |
| `02_merge_psi.py` | Stage 2 — clip PSI, compute logit, pool replicates, compute SDs, merge across cell lines. Mirrors the legacy `run_merge_psi_clipping_no_psuedo.sh` schema and adds `transcript_id` / `exon_start_hg38` / `exon_end_hg38` / `variant_hg38` carry-through and a merged `ALL_WITH_WT.csv`. |
| `02_run_merge_psi.sh` | Wrapper — wires `02_merge_psi.py` to the Stage 1 outputs and the COMPASS replicate-file naming convention. |
| `03_alt_transcript_si_table.py` | Stage 3 — for each ambiguous event, compute PSI at every non-chosen Gencode-annotated alt transcript. |

Each script has a `BASE_DIR=/ESL` (shell) or hardcoded path constants (Python)
near the top — change these to your local base directory before running.

## Stage 1 detail — junction selection

For each event with multiple Gencode-annotated transcripts producing different
intron1 lengths in the supertable, pick one canonical Gencode junction:

1. **Primary-reference vote.** For the lowest-Reference WT (snp == 'none')
   construct, count replicates with valid PSI (`Coverage >= MINCOV`) at each
   candidate junction. Pick a junction with reads in ≥2 reps. Tiebreak
   MANE Select > MANE Plus Clinical > lowest Reference.
2. **Variant-pool fallback** (when the primary reference is a synthesis
   dropout — zero reads anywhere). Score each candidate by the number of
   *event refs* (WT + variants) passing MINCOV in any rep, then by summed
   reads, then MANE priority, then lowest Reference. Only Gencode-annotated
   junctions are considered.
3. **Skip** events with zero reads at any candidate junction across all refs
   and all reps.

For every row in a chosen-junction event the script then rewrites:

- `intron1` / `exon` / `intron2` are re-derived from the row's existing
  `full_seq` by splitting at the chosen `(intron1_len, exon_len)`. `full_seq`
  itself is preserved (it is the physical synthesized 161-nt construct).
- `transcript_id`, `mane_status`, `exon_start_hg38`, `exon_end_hg38`,
  `intron1_len`, `exon_len` are overwritten to the chosen MANE values.

For each per-rep PSI text file (3 columns: `Reference`, `PSI`, `Coverage`),
ambig-event Reference IDs have `(PSI, Coverage)` recomputed from the rep's
pickle at the chosen junction. Rows that no longer pass MINCOV are dropped;
rows that newly pass MINCOV are added. Non-ambig refs are passed through
byte-equivalent.

## Stage 2 detail — merge

Mirrors the legacy merge_psi pipeline:

- PSI clipping to `[0.01, 0.99]` (configurable via `--clip`)
- `logit_PSI = log(clipped / (1 - clipped))`
- Per-replicate `_included` / `_excluded` / `_psi_raw` / `_psi_clipped` /
  `_logit` columns
- Pooled `_pooled_*` columns weighted by Coverage
- `dpsi_pooled = pooled_psi_raw - wt_pooled_psi_raw` per event_id
- `delta_logit_pooled = pooled_logit - wt_pooled_logit` per event_id
- Per-replicate `_sd_psi` / `_sd_logit` / `_sd_dpsi` / `_sd_delta_logit`
- HEK rep handling: variant reps 1+2 (`HEK293_Rep1/2_PSI`), WT reps 3+4
  (`HEK293_WT_Rep1/2_PSI`); WT mean per event_id maps onto variant rows for
  delta computation

Beyond the legacy schema:

- Carries `transcript_id`, `exon_start_hg38`, `exon_end_hg38`, `variant_hg38`
  through from the supertable into every output (per-cell-line + merged).
- Writes a merged `ALL_WITH_WT.csv` filtered to event_ids containing both a
  WT row and at least one variant row.

---

## Stage 3 detail — alt-transcript SI table

For each ambiguous event, enumerates every Gencode-annotated transcript in the
source supertable for that event other than the chosen one. For every row
(WT + variants), computes PSI at the alt transcript's junction across all reps,
plus pooled PSI, dPSI, and delta logit. Output schema mirrors the main CSV
with `_alt` suffixed columns and an `alt_transcript_id` key column.

## Run

```bash
# stage 1 — corrected supertable + patched PSI files
python  01_fix_sj_supertable.py

# stage 2 — merge
bash    02_run_merge_psi.sh

# stage 3 — alt-transcript SI table
python  03_alt_transcript_si_table.py
```

## Schema (master CSV)

Constant columns (carried through from the supertable):

```
Reference, event_id, gene_exon, snp, source, seq_type,
intron1, exon, intron2, full_seq,
transcript_id, exon_start_hg38, exon_end_hg38, variant_hg38
```

Per cell line `<CELL>` (one block of columns each for HeLa, K562, MCF7, HMC3, HEK):

```
<CELL>_pooled_included, <CELL>_pooled_excluded, <CELL>_total_pooled,
<CELL>_pooled_psi_raw, <CELL>_pooled_psi_clipped, <CELL>_pooled_logit,
<CELL>_wt_pooled_psi_raw, <CELL>_wt_pooled_logit,
<CELL>_dpsi_pooled, <CELL>_delta_logit_pooled,
<CELL>_rep{i}_included, <CELL>_rep{i}_excluded,
<CELL>_rep{i}_psi_raw, <CELL>_rep{i}_psi_clipped, <CELL>_rep{i}_logit,
<CELL>_sd_psi, <CELL>_sd_logit, <CELL>_sd_dpsi, <CELL>_sd_delta_logit
```

Replicate count: 2 per cell line for HeLa / K562 / MCF7 / HMC3; 4 for HEK293
(variant reps 1–2, WT reps 3–4).

## Construct geometry constants

```
SHARED_5P = 286   # length of the shared 5' adapter before the variable region
MINCOV    = 10    # minimum included + excluded reads to assign PSI
E_JXN     = (26, 871)    # construct-coordinate exclusion junction

# inclusion junctions for a transcript with intron1_len i1l and exon_len ex:
i1 = (26, SHARED_5P + i1l)
i2 = (SHARED_5P + i1l + ex + 1, 871)
```
